# AI guides

Step-by-step guides for using AI at work and in your job search. Each one comes with prompts you can copy and paste straight into Claude, so you don't need to know how to code.

## Guides

2 guides so far.

| Guide | What you'll get |
|---|---|
| [The 5-Step LinkedIn Playbook](linkedin-playbook.md) | A profile recruiters can find, with a Claude prompt for each step |
| [How to organize your Desktop with Claude](01-desktop-organizer/) | A tidy Desktop with 5 to 8 folders, and a rulebook that keeps it that way |

More coming soon. Want one on something specific? [Suggest a guide](https://github.com/Lily-Tewolde/ai-guides/issues/new?template=suggest-a-guide.yml).
