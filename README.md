# AI guides

Step-by-step guides for using AI at work and in your job search. Each one comes with prompts you can copy and paste straight into Claude, so you don't need to know how to code.

## Guides

<!-- count -->4 guides so far.<!-- /count -->

| Guide | What you'll get |
|---|---|
| [The 5-Step LinkedIn Playbook](02-linkedin-playbook/) | A profile recruiters can find, with a Claude prompt for each step |
| [How to audit and tailor your resume with Claude](04-resume-audit/) | A tailored resume that's checked before it goes out, with a prompt for each step |
| [How to organize your Desktop with Claude](01-desktop-organizer/) | A tidy Desktop with 5 to 8 folders, and a rulebook that keeps it that way |
| [How to organize a messy image folder with Claude](03-image-organizer/) | Your images sorted into folders you pick, with nothing deleted |
